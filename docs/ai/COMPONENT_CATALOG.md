# Nexora Component Catalog

## Purpose

This document provides a catalog reference for frontend components.

The AI should expand this document as components are identified.

## Component Location

Main location:

    src/components/

## Component Rules

Components should:

-   Be reusable.
-   Maintain clear responsibilities.
-   Avoid duplicated logic.
-   Use TypeScript types.
-   Follow existing UI patterns.

## Discovery Process

When adding a new component:

1.  Check if a similar component exists.
2.  Reuse existing patterns.
3.  Add documentation when necessary.
4.  Validate integration.
